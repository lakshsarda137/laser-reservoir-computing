  1. 1Input. One new number each step.
  2. 2Pump. The input, times a fixed random pattern, sets the pump in each of 100 time slots. With the loop on, the delayed light is added too.
  3. 3Laser. Its light output follows the pump, with a lag.
  4. 4Recordings. The light is measured at the end of each slot: 100 numbers per step.
  5. 5Weights. Each recording is multiplied by its own weight. These weights are the only trained part.
  6. 6Sum. The 100 products are added (plus a term for the input and a constant).
  7. 7Prediction. The sum is the guess for the next NARMA10 value.
