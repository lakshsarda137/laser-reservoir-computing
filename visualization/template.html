Laser Reservoir

Each input number changes the pump light hitting a tiny laser. The laser's glow is recorded and used to predict the NARMA10 answer, which depends on inputs from up to 9 steps ago. So the laser has to keep a trace of old inputs. Each input has its own colour, so you can see how long it lingers.

Live simulation of the notebook's model (rate equations from Cho et al. 2016, 100 recordings per input). "Loop off" uses the best settings found without a loop. Score is test NMSE: 0 is perfect, lower is better. For comparison, the software reservoir (ESN) scores 0.067.
